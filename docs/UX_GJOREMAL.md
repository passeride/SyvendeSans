# UX-gjøremål

## Første iterasjon

- [x] Vis om et utkast venter på lokal lagring, er lagret lokalt eller er synket.
- [x] Behold lokal utkastlagring ved fanebytte, lukking og omstart.
- [ ] Sammenlign lokalt utkast med GitHub-versjonen ved konflikt, og la brukeren velge hva som beholdes.
- [x] Åpne wikilenker i lesemodus. Vis mulige mål når flere notater har samme navn.
- [ ] Vis bilder, matematikk og YAML-egenskaper i lesemodus.
- [ ] Test med egne studie- og verkstednotater, også ved nettbrudd og omstart.

## Videre

- [ ] Gjenoppta siste vault med systemets nøkkellager på desktop og Android.
- [ ] Gjør vanlig GitHub-innlogging tilgjengelig på web, og behold utkast ved utløpt tilgang.
- [ ] Legg til lokalt fulltekstsøk med treffutdrag.
- [ ] Flytt og omdøp filer med oversikt over berørte lenker og mulighet til å angre.
- [x] Åpne hurtignotat direkte i Innboks med automatisk navn og fokus i editoren.
- [ ] Test hurtignotat med norsk systemdiktering på fysisk Android.
- [ ] Bedre fokusretur fra palett, snarvei til forrige fane og nylig lukkede faner.
- [ ] Test hele arbeidsflyten med tastatur og skjermleser.
- [ ] Mål p95 for palett og fanebytte (50 ms), lokalt søk i 10 000 stier (100 ms) og åpning av bufret notat (150 ms), også under synk.
